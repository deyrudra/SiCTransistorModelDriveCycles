# Pathfinding

This documents the pathfinding between point A to point B on the map and drawing the route on the visualization.

Two need files were created:

- `route_planner.py`:

  - A* Algorithm 

- `visualization.py`:

  - Now includes nearest road node to a mouse click

  - Storing `route_start` and `route_end`

  - Running A* between them and drawing the resulting route.
